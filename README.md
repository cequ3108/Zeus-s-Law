# 宙斯法則

在台灣提供或請求幫助的小網站。食物、交通，或其他需要都可以。沒有現金換手。功德在人之間流動，1 功德等於 1 元新台幣，但不能兌換現金。

這是給大約一千人使用的第一版：一個 Node.js 程序、一個 SQLite 檔案。之後可以放到有持久磁碟的免費主機，不需要另外的資料庫服務。

## 本地執行

需要 Node.js 22 以上。

```bash
npm install
npm start
```

瀏覽器打開 <http://localhost:3000>。

開發時可以改用 `npm run dev`，存檔後會自動重啟。

資料存在 `data/zeus.db`。這個檔案不會進版本庫。想重來，把伺服器停掉再刪掉它。

執行測試：

```bash
npm test
```

## 開發模式的驗證碼

沒有設定簡訊金鑰時，程式不會呼叫簡訊商，也不會假造一組金鑰。驗證碼會直接顯示在驗證頁。頁首會標成示範站，並寫明目前是開發模式。伺服器記錄只會寫「驗證碼顯示在登入頁」，不會把驗證碼寫進記錄。

這只適合在自己的電腦試用。正式環境請改接簡訊，見下方 EVERY8D。

## 創辦人與福利機構

公開註冊只會建立一般使用者，功德額度與功德都是 100。沒有創辦人或機構的註冊選項。

把一支手機設成創辦人（功德與額度都是 100,000,000）：

```bash
npm run seed:founder -- 0912345678 創辦人
```

然後用這個號碼登入。創辦人可以在「管理」頁：

- 用手機號碼直接建立福利機構，或把現有的一般使用者升為機構
- 審核一般使用者送出的機構申請
- 封鎖收取現金的帳號，或解除封鎖

福利機構的功德與額度是 1,000,000。機構只能發布「我需要」。

再執行一次種子指令不會把創辦人的餘額補回去，避免變成鑄造功德的方法。

## 接上 EVERY8D

簡訊只從 `src/sms.js` 送出。要改接時，設定環境變數，不要把帳號密碼寫進程式或版本庫：

```bash
SMS_PROVIDER=every8d
EVERY8D_UID=你的帳號
EVERY8D_PWD=你的密碼
# 選填，預設是 EVERY8D 的 SendSMS 位址
EVERY8D_API_URL=https://api.e8d.tw/API21/HTTP/SendSMS.ashx
```

可以參考 `.env.example`。這個程式不會自動讀 `.env`，啟動前請自己匯出變數，或由主機的環境設定帶入。

若指定了 `every8d` 卻沒有帳號或密碼，發送會失敗，不會偷偷改回開發模式。

正式環境另外請設定：

```bash
NODE_ENV=production
SESSION_SECRET=一長串隨機文字
DB_PATH=/你的持久磁碟/zeus.db
```

`NODE_ENV=production` 時，登入 cookie 只在 HTTPS 傳送。

## 產品規則

### 帳號

- 用台灣手機號碼註冊，以簡訊驗證碼確認。不存放身分證或護照。
- 三種角色：一般使用者、福利機構、創辦人。
- 新的一般使用者：功德額度 100、功德 100。1 功德等於 1 元新台幣。
- 創辦人：兩者都是 100,000,000。只能用種子指令設定，不是公開註冊。
- 福利機構：兩者都是 1,000,000。不是公開註冊。創辦人可以直接建立，或審核申請後通過。

### 發布

- 雙方都可以發布。「我可以提供」或「我需要」，描述必填，並標示一個新台幣金額（功德）。
- 福利機構只發布「我需要」。幫忙的人獲得功德，由機構付出。
- 一般使用者若是付出功德的一方（接受幫助的人），功德減去標示金額後必須大於 0，才能接下或被配對。例如 100 功德不能接標示 200 的貼文，因為會變成 -100。餘額不允許變成負數。剛好扣到 0 也不行接，因為扣完必須大於 0。
- 提供幫助的人是收入功德，不受上一條限制。否則機構無法把較大的金額付給只有 100 功德的幫手。
- 被封鎖的人不能發布，也不能接下。

### 結算

- 互助完成後，雙方各自填寫認為值多少新台幣。結算金額是較低的那個。任一方填 0，結算就是 0。
- 功德額度只增不減。雙方額度都加上結算金額。
- 功德的移動：接受幫助的人支出結算金額，提供幫助的人收入。福利機構的需要，機構是支出的一方，幫手是收入的一方。
- 同一對帳號在台北時間的同一個日曆日最多結算一次。這一次也是當天彼此額度唯一會增加的時候。隔日再做一次是允許的，額度會再增加。這是規則，不是漏洞。同一天跟不同的人結算，各自算一對。
- 填 0 也算用掉當天這一次。
- 若結算會讓付出的一方變成負數（包含機構功德不夠），這則不能完成，餘額維持原狀。可以改填較低的金額。
- 依這些規則，功德不會超過額度。沒有另外鑄造功德的功能。

### 星等與現金

- 結算後雙方互相給 1 到 5 顆星。星等顯示在個人頁，雙方與其他人都看得到。
- 評分可以留下備註。備註會存進資料庫，但畫面不顯示，連留下的人自己也看不到。
- 平台禁止現金。頁面上有固定標示。創辦人可以因收取現金封鎖使用者。被封鎖的人不能發布或接下。
